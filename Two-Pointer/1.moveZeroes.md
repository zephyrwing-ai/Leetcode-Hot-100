大体思路：
因为他的要求是保持非零元素的相对位置，我们需要对非零元素进行控制，那么我们对非零元素进行操作，这样控制权就会在我们手上
怎么进行操作呢，使用双指针，一个指向零元素一个指向非零元素的时候，就进行交换，使得非零元素在前面，零元素被换到后面
关键在于指针怎么进行移动，肯定是要循环遍历数组里面的每一个元素，使用这样的方式来找出非零元素。固定一个指针一直向右移动，叫做右指针，一个左指针进行交换。

具体思路
1、每一次循环，右指针都会向右移动，当碰到零元素的时候就和左指针下的元素进行交换，那么就说明左指针要一直指向的是已经扫描之后的最后一个非零元素。
2、由于交换之后，左指针指向的元素变成了零元素，所以这时候需要我们将其向右边移动一下

class Solution:
    def moveZeros(self,nums):
        left=right=0
        n=len(nums)
        while right < n:
            if nums[right] != 0:
                nums[right],nums[left]=nums[left],nums[right]#思路1：交换的实现
                left+=1 #思路2：交换之后左指针指向零元素，所以需要移动使其指向非零元素
            right+=1 #思路1：不管怎么样右指针都要向右移动
