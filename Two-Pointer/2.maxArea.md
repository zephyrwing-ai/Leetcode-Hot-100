# Container With Most Water

## 思路

用两边向中间移动指针的方法。

怎么移动？总是移动那个比较短的指针。为什么？因为当你将指针向中间移动的时候，长是在变小的，而你要找的是有没有面积变大的可能，那么只有将高变长才有可能。但是你不能移动长的那边，因为高的上限永远是被短的那边所限制住的，所以你只能移动比较短的那一边，这样才有可能变长，面积才有可能变大。

```python
class Solution:
    def maxArea(self, height: List[int]) -> int:
        right=len(height)-1
        left=0
        s=0
        for i in height:
            if height[right]<height[left]:
                s=max((right-left)*height[right],s)
                right-=1
            else:
                s=max((right-left)*height[left],s)
                left+=1
        return s
```
