思路是计算每一个元素他能够存储的水量有多少，然后进行叠加起来。那怎么计算每一个元素能够存储的水量都是多少呢，计算面积。这个面积总面积你选哪个计算，怎么知道长是多少、宽是多少。长就是1，款就是用两边最大值中那个比较大的减去当前的元素的高即max(leftMax(i),rightMax(i)-height[i])，为什么这样可以得到这个宽呢，可以去看一下动态规划方法。然后如何得到leftMax(i)以及rightMax(i)呢，因为每一个元素他都有左右两边的最大，所以使用定义一个leftMax数组来存储每一个元素左边的最大值是多少，定义一个rightMax数组来存储每个元素右边的最大值是多少，一开始都定为0，然后遍历更新相应的元素的大小

class Solution:
    def trap(self,height:List[int])->int:
        if not height:
            return
        n=len(height)
        
        leftMax=[height[0]]+(n-1)*[0]
        for i in range (0,n):
            leftMax[i]=max(leftMax[i-1],height[i])
        
        rightMax=(n-1)*[0]+[height[n-1]]
        for i in range (n-2,-1,-1):
            rightMax[i]=max(rightMax[i+1],height[i])

        ans=sum(min(leftMax[i],rightMax[i])-height[i] for i in range(n))

        return ans
