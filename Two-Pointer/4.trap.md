# Trapping Rain Water

## 思路

计算每一个元素他能够存储的水量有多少，然后进行叠加起来。

怎么计算每一个元素能够存储的水量？计算面积。长就是 1，宽就是用两边最大值中那个比较小的减去当前元素的高，即 `min(leftMax[i], rightMax[i]) - height[i]`。

如何得到 `leftMax[i]` 以及 `rightMax[i]`？因为每一个元素他都有左右两边的最大值，所以定义一个 leftMax 数组来存储每一个元素左边的最大值，定义一个 rightMax 数组来存储每个元素右边的最大值，一开始都定为 0，然后遍历更新。

```python
class Solution:
    def trap(self,height:List[int])->int:
        if not height:
            return
        n=len(height)

        leftMax=[height[0]]+(n-1)*[0]
        for i in range (0,n):
            leftMax[i]=max(leftMax[i-1],height[i])

        rightMax=(n-1)*[0]+[height[n-1]]
        for i in range (n-2,-1,-1):
            rightMax[i]=max(rightMax[i+1],height[i])

        ans=sum(min(leftMax[i],rightMax[i])-height[i] for i in range(n))

        return ans
```
